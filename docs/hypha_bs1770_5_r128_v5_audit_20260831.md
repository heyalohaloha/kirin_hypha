# Hypha BS.1770-5、EBU R 128 v5監査

Status: 規格差分監査とTech 3342 LRA実測完了。公式test set全体による製品適合試験は未完了

Date: 2026-08-31

Branch: `codex/hypha-meter`

## 1. 結論

Hyphaのmonoとstereoの2MIX計測は、現行のITU-R BS.1770-5でもAnnex 1の対象である。

BS.1770-4からBS.1770-5への改訂は、object-based audio用Annex 4、高度音響方式用のloudspeaker configuration IとJ、configuration Gの訂正を追加した。

Hyphaが使うAnnex 1のK-weighting、400 ms block、75% overlap、−70 LKFS absolute gate、−10 dB relative gateと、Annex 2のTrue Peak方式は、この改訂対象に含まれない。

したがって、BS.1770-5への移行を理由に2MIXの計測アルゴリズムを変更しない。

一方、Hypha自身で公式test setを完走していないため、UIとCaptureの規格表示は現行どおり版番号を付けない`ITU-R BS.1770`に留める。

## 2. 一次資料の差分

### 2.1 ITU-R BS.1770-5

[ITU-R BS.1770-5](https://www.itu.int/rec/R-REC-BS.1770-5-202311-I/en)は2023年11月22日に承認され、現行版として公開されている。

ITUの改訂通知[CACE/1076](https://www.itu.int/dms_pub/itu-r/md/00/cace/cir/R00-CACE-CIR-1076!!PDF-E.pdf)は、BS.1770-5の技術変更を次の範囲としている。

- object-based audio、またはchannel-based audioとobject-based audioの組合せを測るAnnex 4の追加
- BS.2051-3に合わせたloudspeaker configuration IとJの追加
- Annex 3にあるloudspeaker configuration Gの訂正
- Keywords、参照番号、AppendixからAttachmentへの名称変更

公式のBS.1770-4本文とBS.1770-5本文も比較した。

Annex 1のK-weighting係数、channel weighting、gating式とAnnex 2のTrue Peak方式に、2MIXの測定値を変える規範差分はなかった。

### 2.2 EBU R 128 v5

[EBU R 128 v5.0](https://tech.ebu.ch/publications/r128)のDocument Historyは、2023年11月版の変更をR 128 s3、R 128 s4、Tech 3401への参照追加としている。

Programme Loudness、LRA、Maximum True Peak Levelの計測式はv5.0で変更されていない。

### 2.3 EBU Mode

メーターとしての要求は、R 128本体だけでなく[EBU Tech 3341 v4.0](https://tech.ebu.ch/publications/tech3341)で確認した。

Tech 3341 v4.0の変更はeditorialとformattingであり、v3.0から計測内容は変わっていない。

同文書はlive meterにM、S、I、Maximum M、Maximum S、start、pause、continue、reset、LRAの最初の60秒における不安定表示、absoluteとrelativeの両scaleなどを求める。

HyphaはR-22によりtarget、normalization、合否判定を表示せず、現時点ではMaximum M、Maximum SとEBU +9/+18 scaleも製品契約に含めていない。

このため、HyphaはBS.1770に基づく事実値を表示するが、製品全体を`EBU Mode`とは表示せず、EBU R 128 logoも使用しない。

## 3. 現行実装との対応

HyphaはCargo.lockで`ebur128 0.1.10`を固定している。

同crateはBS.1770-4とEBU Tech 3341、3342を実装対象とし、M、S、I、LRA、True Peakを提供する。

Hyphaの`MeasureEngine`は`Mode::M | Mode::S | Mode::I | Mode::LRA | Mode::TRUE_PEAK`を有効にし、100 ms単位で同じ音声を投入する。

Mは400 ms、Sは3 s、IとLRAはMeter Session、True Peakは直近400 msとSession最大として分けている。

プラグイン入力はmonoまたはstereoに限定されるため、BS.1770-5で追加されたAnnex 3とAnnex 4の実装はHyphaの製品範囲外である。

## 4. 検証済み範囲

| 項目 | 結果 | 保証できる範囲 |
|---|---|---|
| BS.1770-4とBS.1770-5の公式本文比較 | pass | mono、stereoのAnnex 1とTrue PeakのAnnex 2に数値差分がない |
| `ebur128 0.1.10`の依存固定 | pass | 実際にbuildされる計測実装の版が一意である |
| S-1の独立K-weighting point test | pass | 1 kHz、48 kHzにおける係数とLUFS-I、PSRの対応 |
| S-1からS-5のproject test | pass | Hyphaのchunking、Session集計、無音処理、既知信号の回帰 |
| True Peak project fixture | pass | Hypha固有fixtureに対する直近値とSession最大の回帰 |
| EBU Loudness test set v05、Tech 3342 LRA 6素材 | pass | 固定`ebur128 0.1.10`とHyphaの100 ms wrapperが期待値±1.0 LU、相互差±0.1 LU以内 |
| EBU Loudness test set v05、Tech 3341および残りの項目 | pending | 公式70音源全体によるM、S、I、TPを含むminimum compliance |

S-2、S-3、S-5は同じ`ebur128`で目標LUFSへ校正した信号なので、独立した規格適合証拠として扱わない。

依存crateのREADMEとCIは公式test setのpassを表明しているが、Hyphaの固定版とwrapperをこの環境で実行した結果には置き換えない。

## 5. 公式test setの取得と部分実測

[EBU Loudness test set v5.0](https://tech.ebu.ch/publications/ebu_loudness_test_set)は70音源、87.4 MBの公式配布物である。

2026年9月1日に公式配布物をリポジトリ外へ取得した。
ZIPは91,631,421 bytes、70 WAVで、SHA-256は`9cc500b4df83f7c21855c74dce795ef5209a752bf884253ae57d0ce512efb062`である。

Tech 3342の6素材を、固定`ebur128 0.1.10`とHyphaの`MeasureEngine`へ同じPCMで投入した。
Hypha側は実運用と同じ100 ms境界で処理し、全6素材が期待LRAの±1.0 LU以内、参照実装との差が±0.1 LU以内でpassした。

この結果はTech 3342のLRAだけを保証する。
Tech 3341と70素材全体を実行していないため、EBU test set全体の適合を示す結果として扱わない。

## 6. 公開前ゲート

公式test setはGPLリポジトリへcommitせず、ローカル専用領域で保持する。

残るTech 3341の対象素材は、固定`ebur128 0.1.10`とHyphaの`MeasureEngine`を100 ms chunkで通し、M、S、I、TPを同じ許容値で検証する。

monoとstereoの対象testがすべてpassした後に限り、版番号を表示する必要性を再判断する。

版番号を表示する場合も、製品範囲を`ITU-R BS.1770-5 Annex 1/2, mono/stereo`と限定し、Annex 3、Annex 4またはEBU Modeへの適合を暗示しない。
