# Screen language and keys

The screen is in English or Japanese, chosen under MENU → Display → Language. Keys work while the
Hypha window has focus; press F for the list of keys that work now. Keys Hypha does not use go to
the DAW.

[Back to the README](../../README.md#the-full-manual)

## Screen language

Hypha's screen is in English or Japanese. **MENU → Display → Language** chooses **English** or
**日本語**; until a choice is made, Hypha follows the system's display language. The choice is saved
for every PRE and POST, and open editors switch at once. In Japanese, what explains or reports is
Japanese: status lines, notices, hover help, menus, guidance and dialog text. Measurement labels,
abbreviations, legends, units and values (LEVEL, LUFS, TP, POST / Δ, MARK) stay as written, so the
layout and the measurement vocabulary are the same in both languages. Action labels are translated,
except Blind's **REVEAL** and **END**, which read the same in both. Names you give stay as written. The language changes
only what is drawn; plug-in names shown by the host, Record, `plugin_data`, the data exchanged with
Kirin OS, and every measurement stay the same.

A control that cannot be used now is greyed. Clicking it, or pressing its key, shows why on the
notice line and what makes it usable, for example **Choose the PRE first** or **Finish Keep / Record
before PRE / POST Blind**. A greyed menu item has its reason on the line under it. When Hypha changes
the view by itself, the notice line says why, for example **2MIX has no DRUM; showing METERS**.

## Keys

Click the Hypha window and its keys work there. Hover a control to see its key, or press **F**
(**MENU > KEYS**) for the list of what works now. A key Hypha does not use goes back to the DAW, and so
do Space, the numeric keypad and anything held with Cmd, Ctrl or Alt. A key the DAW takes first does not
reach Hypha.

| Keys | Does |
|---|---|
| Shift+1 to Shift+5 | LEVEL, TIME, FREQ, SPACE, REFERENCE |
| Q, W, E | LISTEN, A/B (asks for PRE2 and the placement first), BLIND (Version Blind in REF) |
| 1, 2 | PRE and POST in LISTEN, A and B in A/B, SOURCE 1 and 2 in BLIND |
| 1, 2, 3, 4 | A, B, C and V in REF |
| G, Shift+G | MATCH, the MATCH / AUTO choice |
| T, Shift+T | END, RETURN |
| Shift+E | REVEAL |
| A / D, Shift+A / D | Song, Version in REF |
| X / C, Shift+X / C | TIME page or REF tab, Cue in REF |
| Shift+Q / W | Reference set or CHECK SET in REF |
| Z, Shift+Z | Absolute reading, Δ |
| V, Shift+F, Shift+V | Hybrid VU, TP / Clip CLEAR, RESET (asks first) |
| Tab, Return, Esc | Next control, press it, close the list |

Approving a level change, Record / Keep and the pair have no key of their own: Tab reaches them.
