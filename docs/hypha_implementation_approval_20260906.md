# Hypha 推奨方針の実装承認記録

日付: 2026-09-06。
根拠: Daisuke の「推奨で良いです」と、Blind を既存 2 枠のうち 1 枠に限定する追加指示。
これは実装着手の承認記録であり、測定精度、RT 安全性、実機試験、公開準備の合格記録ではない。
実装済み・研究用試作・検証待ちの最新区分は [実装と検証の記録](hypha_implementation_progress_20260906.md) を参照する。

## 承認された方針

1. SPACE は広帯域 EARLY と 20 dB 相当減衰時間を扱う。奥行きや RT60 と呼ばない。DEPTH、REPEAT、帯域別は今回の実装範囲に含めない。
2. PRE/POST Blind は同じ再生区間の不変コピーと固定 Gain Match を使う。通常計測と正本 Record は変更しない。必要な基準側減衰は開始前に明示承認を受け、中断後に急な音量復帰を行わず、減衰保持からの復帰を別操作にする。
3. 管理対象の同一 DAW participant scope で Blind と Keep / All Keep を相互排他にする。既存 Record を自動停止しない。
4. ローカル PRE/POST Blind は Hypha 単体で使用できる。2MIX と TRACK/STEM、mono と stereo を含む。登録 Reference の Kirin OS 権限は変更しない。
5. 今回は共通情報メニューから公式更新情報とダウンロードへ進む手動導線を作る。自動通信、最新版の自動検知、自動インストールは追加しない。

現行 ATTACK を DRUM と明示して TRACK/STEM 側へ区別する方針も採用する。
2MIX 専用検出器が検証を通るまで DRUM を 2MIX 用として代用せず、文脈変更で DRUM の解析要求を終了する。
SPACE の固定区間試作と 2MIX 用 ATTACK の検出性能評価は別の合否単位を維持する。

## Blind の 2 枠制約

実装を確認すると、既存の上限はウィンドウ数ではなく、任意解析を動かす `AnalysisLease` の 2 所有枠である。
大きな表示へリサイズした事実だけでは、この枠の所有は証明できない。
TIME の HISTORY / RUN は枠を所有せず、現行の Reference はこの枠の取得にまだ接続されていない。

Blind の入場条件は、対応する大きな表示に加え、既存 Analysis 枠を所有していることとする。
PRE と POST で 2 枠を別々に使わず、POST が 1 枠を所有し、その PRE は取得元として従属する。
同じ 2 枠のうち、Blind 所有者は同時に 1 つだけとする。
もう一方の枠を消したり取り上げたりせず、その枠では Blind の開始を不可にする。
空きが戻っても、自動で Blind を開始しない。

UI のボタン非活性だけを排他の根拠にしない。
非 RT の開始処理で、解析枠、単一試聴所有権、Record 排他を同じ取得順序に従って予約し、失敗時は新たに取得した予約だけを返す。
2 つの開始が競合した場合も勝者は 1 つで、3 番目の解析所有者を作らない。
Reference Blind と PRE/POST Blind を独立した試聴枠として動かさない。
他方の枠が通常解析を継続できることと、Blind 中に識別情報を画面へ出せることは別条件とする。

終了、縮小、editor 閉鎖、ペア変更、prepare、停止、seek、offline render、worker 再起動では試聴を中断し、RT の出力確認後に予約を解放する。
承認済み減衰を保持している間は、別の Blind と Record を開始できない。
単に UI が閉じたことや予約の timeout だけで、音量復帰や Record 許可を行わない。
プロセス分離ホストで参加範囲を確認できない場合は、ローカル PID の排他だけで安全と判断せず、新機能を開始しない。

## 実装と検証の順序

- A0: 共通情報メニュー、手動更新導線、DRUM の識別と文脈別入口。通常の音声経路を変更しない。
- G1: 実音入力と解析解による SPACE の固定区間試作。2MIX の開発用素材と holdout の台帳、二人の注釈者による検出性能評価。
- BL 実証: 同区間取得と PDC、短い TRACK の Gain Match、枠と Record の競合、減衰保持と復帰、下流の正本保護。
- G2 以降: 合格した定義と容量を固定して接続し、両 OS と実ホストの必須試験を実施する。

これは残りの機能を承認なく Phase 2 へ送る決定ではない。
G1 と BL 実証の結果なしに性能閾値や音声の安全性を成立済みとしない。
実験用コードを製品への接続済みと数えず、実行できなかった試験を pass にしない。

## 現在維持する操作境界

Windows は他作業の占有中のため触らない。
Notion への書込み、別タスクの作成、他担当へのメッセージ送信は行わない。
インストール、署名、notarize、公開、push は今回の着手に含めない。
既存の JUCE ローカル差分と未追跡の別件 handoff は保存する。
