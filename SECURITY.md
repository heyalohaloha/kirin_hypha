# Security policy

Do not disclose vulnerabilities, exploit details, credentials, or private audio in public Issues,
pull requests, Discussions, or logs.

## Private reporting

GitHub Private Vulnerability Reporting is enabled. Use this repository's
**Security → Report a vulnerability** form:
[Submit a private report](https://github.com/heyalohaloha/kirin_hypha/security/advisories/new).
This creates a private report for the maintainers; do not post the same details publicly.

## Scope and response

Reports about the latest public release and current main are in scope. Older releases may require
upgrading; no fixed response deadline or support commitment is implied. Include the affected
version/commit, host/OS, impact and minimal reproduction privately. Use synthetic audio and redact
personal information and credentials. Maintainers assess reports, reproduce the issue, and coordinate
a fix and disclosure with the reporter. If a credential is exposed, revoke/rotate it before relying
on source cleanup. Preserve immutable release provenance and do not rewrite history automatically.
